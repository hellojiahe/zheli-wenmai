# 浙里文脉 · 文保空间图集

用交互地图探索第一至第八批全国重点文物保护单位的空间分布，聚焦浙江文物、历史年代、杭州高程与浙江河网。

当前公开展示地址：[浙里文脉](https://zheli-wenmai-demo-1031.earlyfawn35.chatgpt.site/)。

## 功能

- 全国概览：省域数量、全国占比、类型筛选、点位与热力分布。
- 浙江文物：城市、文保类型与名称检索。
- 年代演变：14 个历史时期的不同颜色、6 个宽时期分组及动画。
- 杭州高程：按年代、类型、海拔带组合筛选。
- 浙江水系：浏览来源数据中的河网缓冲区及对应统计。
- 研究图件：原始成果图、高清图片及年代动画。

## 本地运行

安装 Node.js 20 或更新版本，执行 `node preview.cjs`，在浏览器打开 http://127.0.0.1:4173/ 。

运行 `node tools/verify_atlas.cjs` 可检查数据与交互。

## GitHub Pages

在仓库 Settings → Pages 中选择 Deploy from a branch，分支 main、目录 /docs。

## 统计口径与许可

全国原始点记录为 5,066 条，省域空间统计合计 5,058 处；浙江点记录 279 条，省域空间统计 278 处。杭州 47 条研究样本中 46 条具有有效高程。
